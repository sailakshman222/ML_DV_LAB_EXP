## How to run

- Install Python 3 and run `python -m pip install -r requirements.txt`.
- Open JupyterLab using `python -m jupyter lab` and run the notebooks.
- DV notebooks use Python/Plotly and include Power BI Desktop procedures. The retail CSVs are synthetic instructional data, not real transactions. ML uses standard scikit-learn datasets and illustrative marks.
- Interactive charts use CDN scripts and may not render on GitHub; open locally in Jupyter. The dashboard HTML can be opened in a connected browser.
- Native Power BI `.pbix` or Tableau `.twb` files are not included. If required, follow the Power BI procedures and save the reports in DV.
